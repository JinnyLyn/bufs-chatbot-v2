## 주요점검사항3. 플립러닝(VOD) 수업 차시 배정 

플립러닝 형태 수업은 [차시별 출결 합산]에 날짜가 배정되어 있지 않습니다. 

**==> picture [362 x 236] intentionally omitted <==**

**==> picture [417 x 265] intentionally omitted <==**

플립러닝 등 온라인 수업은 [차시별 출결 합산]에서 각 주차 마 지막 수업으로 배정되어 있으며, 플립러닝 수업은 수업일자가 표시되지 않습니다. 

플립러닝 동영상 수업은 반드시 수업일(온라인 강좌)로 표기된 차시 에 배정하여야 합니다.
