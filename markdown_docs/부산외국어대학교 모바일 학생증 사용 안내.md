## 3. 모바일 학생증/신분증 발급 

어플 실행 후 메인 우측 상단 모바일 학생증/신분증 버튼 클릭하면 최초 발급 화면으로 이동합니다. 

**==> picture [154 x 252] intentionally omitted <==**

**==> picture [154 x 251] intentionally omitted <==**

**==> picture [169 x 251] intentionally omitted <==**

- 최초 발급 받기를 통해서 모바일 학생증 또는 신분증이 발급됩니다. 

- 모바일 학생증 및 신분증은 보안상 30초간 유효하며, 30초가 지난 경 우 새로고침 버튼을 통해 갱신 가능합니다. 

- QR코드를 도서관 등의 전용 리더기에 인식하면, 학생증 및 신분증이 인증되어 도서 대출, 좌석 배정 등의 서비스를 이용할 수 있습니다.
